# Security policy

## Supported version

The default branch is the supported reference. This project is educational infrastructure and is not offered as a hosted service.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing exploit details, credentials, or sensitive logs.

## Deployment responsibility

The repository demonstrates secure defaults such as input validation, secret redaction, non-root containers, rate limiting, bounded database operations, and dependency scanning. A real deployment still needs organization-specific authentication, authorization, TLS termination, network policy, secret management, backups, restore tests, and incident response.
